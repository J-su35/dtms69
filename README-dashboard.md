# DTMS vs AMI Dashboard

Create and activate a virtual environment, then run `pip install -r requirements-dashboard.txt` and `streamlit run app.py`. Open http://localhost:8501; use `Ctrl+C` to stop. `reports/comparison_result.parquet` is required. Other report files are optional. If port 8501 is in use, run `streamlit run app.py --server.port 8502`.
